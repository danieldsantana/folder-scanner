# Folder Scanner

A simple command-line tool to scan the structure of a directory and export the results in different formats.

## About

I often need to inspect the structure of folders and files, and I usually end up creating a small script from scratch whenever I need to do it.

This project is meant to be a reusable tool that I can keep around and use whenever I need to scan a directory.

## Planned features

* [ ] Ask for the directory path
* [ ] Scan folders recursively
* [ ] Scan files recursively
* [ ] Choose between folders, files, or both
* [ ] Select which information to collect

  * [ ] Name
  * [ ] Extension
  * [ ] Size
  * [ ] Path
* [ ] Export results as TXT
* [ ] Export results as CSV
* [ ] Export results as XML
