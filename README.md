# Folder Scanner

A simple command-line tool to scan the structure of a directory and export the result as a text file.

## About

I often need to inspect the structure of folders and files, and I usually end up creating a small script from scratch whenever I need to do it.

This project is meant to be a reusable tool that I can keep around and use whenever I need to scan a directory.

## Features

- Ask for the directory to scan
- Choose what to scan
  - Folders only
  - Folders and files
- Scan the directory recursively
- Generate a tree representation of the directory
- Ignore common development directories
- Handle inaccessible directories
- Export the result as TXT
- Avoid overwriting existing results
